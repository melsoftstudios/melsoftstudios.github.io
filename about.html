About Molsoft Games

Small studio.
Big curiosity.

Molsoft Games is an independent game development studio based in Casablanca, Morocco. We focus on approachable casual games for web and mobile, while exploring creative software concepts.

💡

Our mission

Create accessible, delightful digital experiences with clear ideas, polished interactions, and a playful personality.

🛠️

Our process

We start with an idea, prototype core interactions, evaluate usability, and refine projects through iteration.

🌍

Our direction

Build a sustainable portfolio of original games and practical software for audiences across digital platforms.

Development workflow

We use established development environments and design workflows according to each project's needs.

Development tools

Our workflow may involve tools such as Xcode, Android Studio, Visual Studio Code, and common web development technologies. This is a description of possible development environments, not an endorsement or partnership.

Rooted in Casablanca

Our studio draws inspiration from playful design and everyday creativity.
